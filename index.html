How it works

  1. 01

    Show your bookmarks bar

    ⌘ + Shift + B on a Mac, Ctrl + Shift + B elsewhere.

  2. 02

    Drag the tool's button onto it

    Each tool has a button named after it. Drag the button, not the card, and the bookmark arrives named — emoji included. No renaming afterwards.

  3. 03

    Pick a set, export a folder

    Tick tools, download bookmarks.html, then import it in your browser's bookmark manager.

Bookmarklets run with the permissions of the page you click them on. Clipboard, camera and screen-capture tools ask the browser first. If dragging is blocked, use Copy and paste the code into a new bookmark's URL field.
